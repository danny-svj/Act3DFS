# 67GYM

Sistema web para la gestión de un gimnasio.

## Instalación

```bash
git clone https://github.com/danny-svj/Act3DFS.git
cd Act3DFS
npm install
node server.js
```

Abrir en el navegador: **http://localhost:3000**

## Tecnologías

- Node.js + Express
- JWT (autenticación)
- bcrypt (encriptación)
- HTML, CSS, JavaScript
